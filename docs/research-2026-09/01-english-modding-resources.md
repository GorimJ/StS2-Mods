# STS2 modding resources — English survey (2026-09-04)

Compiled by a research subagent (WebSearch/WebFetch). **[READ]** = read from the source; **[INFER]** = inference.

## 1. tutorials.sts2modding.com

Site index says "Updated 2026-03-07, supports public-beta", individual pages dated up to 2026-07-16. Chinese-language (CC BY-NC-SA), authored by "Reme" (GlitchedReme). Source: https://github.com/GlitchedReme/SlayTheSpire2ModdingTutorials.

- **Choose Base Library** (https://tutorials.sts2modding.com/docs/03-choose-base-library/, 2026-07-16) [READ]: compares BaseLib vs **RitsuLib** (https://github.com/BAKAOLC/STS2-RitsuLib, NuGet `STS2.RitsuLib`, v0.4.27 on 2026-06-19, docs https://sts2-ritsulib.ritsukage.com/). Both support non-Spine character animation; "RitsuLib offers state machines and custom animation management; BaseLib accepts vanilla animation names only." RitsuLib recommended for character mods (timelines, lifecycle events, secondary resources). A BaseLib→RitsuLib migration guide exists.
- **Add New Character (BaseLib)** (https://tutorials.sts2modding.com/docs/04-add-new-character/) [READ]: extend `PlaceholderCharacterModel`; create `CustomCardPoolModel`/`CustomRelicPoolModel`/`CustomPotionPoolModel`, tag content with `[Pool(typeof(YourPool))]`. Combat scene (`CustomVisualPath`): Node2D root with `%Visuals` (SpineSprite, Sprite2D or AnimatedSprite2D), `%Bounds` (Control), `%IntentPos`, `%CenterPos` (Marker2D). Spine animation names: `idle_loop`, `attack`, `cast`, `hurt`, `die`. Merchant scene: Node2D with one SpineSprite, plays `relaxed_loop`. Rest-site scene: Node2D + `ControlRoot` (Control) containing `SelectionReticle`, `Hitbox`, `ThoughtBubbleRight`, `ThoughtBubbleLeft`; Spine auto-plays `overgrowth_loop`/`hive_loop`/`glory_loop` per act. Energy counter: Control with `EnergyVfxBack`, `Layers`→`RotationLayers`, `EnergyVfxFront`, `Label`. Gotchas: add `ScriptManagerBridge.LookupScriptsInAssembly(typeof(Entry).Assembly)`, disable "Convert Text Resources to Binary", all nodes need `%` unique names. Sample scenes provided (`test_character.tscn`, `test_energy_counter.tscn`, `test_character_merchant.tscn`, `test_character_rest_site.tscn`).
- **Character Animation (RitsuLib)** (https://tutorials.sts2modding.com/docs/04-ritsulib/04-15-2-character-animation/) [READ]: (a) `VisualCueSet` via `ModVisualCues.CueSet()` with `Single("idle", "res://.../idle.png")` and `Sequence("attack", seq => seq.Frame(...))`; preset `ModAnimStateMachines.StandardCue()` gives idle/hit/attack/cast/dead/relaxed. (b) `RitsuGodotNodeFactories.CreateFromScenePath<NCreatureVisuals>()` auto-conversion. (c) custom state machines: override `SetupCustomCreatureAnimator()` (Spine, `AnimState`, `CreatureCmd.TriggerAnim()` / `.WithAttackerAnim()`), or `SetupCustomCombatAnimationStateMachine()` with `ModAnimStateMachineBuilder.Create().AddState(name, loop).AsInitial().Done().WithNext().AddAnyState().BuildForVisualsRoot()`. `CharacterWorldProceduralVisualSetBuilder.Create()` builds merchant/rest-site visuals without .tscn.
- **Card Art & Spine** (https://tutorials.sts2modding.com/docs/05-card-art-and-skin-replacement/) [READ]: game uses **Spine 4.2.43**; older exports need conversion (mentions "SpineSkeletonDataConverter"). Install the spine-godot extension (precompiled build shared via cloud storage on the page), drop `.atlas/.skel/.png`, create `SpineSkeletonDataResource`. Also 3D models via `SubViewportContainer→SubViewport→Camera3D` with transparent BG.
- **Secondary Resources (RitsuLib)** (https://tutorials.sts2modding.com/docs/04-ritsulib/04-22-7-secondary-resources/) [READ]: `SecondaryResourceRegistry`, `SecondaryResourceDefinition`, `SecondaryResourceCmd.Gain/Lose/Spend/Set`, `RegisterCombatUi()` → `NSecondaryResourceCounter` near energy, `RegisterCardUi()` → `NSecondaryResourceCardCostUi`, `ISecondaryResourceHookListener`, `{Mana:secondaryResourceIcons()}` text vars. Closest ready-made "custom resource bar".
- Also: Frame Animation (AnimatedSprite2D/SpriteFrames, `AnimationFinished += QueueFree`), Texture Atlas, VFX, Shader, Health Bar Overlay, Workshop Upload, Beta→Release migration (`EnergyVfxBack/Front` replaced `BurstBack/Front`; manifest needs `min_game_version`).

## 2. BaseLib-StS2

- **Version**: NuGet `Alchyr.Sts2.BaseLib` **3.4.5 (2026-08-14)** [READ]. April was ~3.0/3.1; 3.4.0 shipped 2026-07-31.
- **Changelog since May** [READ]: 3.1.3 (May 13) "Godot animation improvements", custom rest-site options; 3.1.7 death-anim playback w/ cancellation; 3.3.6 (Jul 17) "healthbar forecast, **wip custom resources**"; 3.4.0 "beta compat, show multiple starting relics in char select, add custom chars to stats screen"; 3.4.1 "fix for missing form vfx node in character models"; 3.4.4/3.4.5 beta fixes, linked rewards, custom credits. ModTemplate installs as `Alchyr.Sts2.Templates` v2.5.1.
- **CustomCharacterModel.cs** (https://raw.githubusercontent.com/Alchyr/BaseLib-StS2/master/Abstracts/CustomCharacterModel.cs) [READ]: virtuals `CustomVisualPath`, `CustomTrailPath`, `CustomEnergyCounterPath`, `CustomRestSiteAnimPath`, `CustomMerchantAnimPath`, `CustomCharacterSelectBg/IconPath/LockedIconPath/TransitionPath`, `CustomMapMarkerPath`, `CustomArm*TexturePath`, `CustomAttackSfx/CastSfx/DeathSfx`, `AttackAnimDelay`=0.15f, `CastAnimDelay`=0.25f, `DeathAnimTime`=1.5f (Godot anims with "Dead"/"die" only), `NCreatureVisuals? CreateCustomVisuals()`, `CreatureAnimator? SetupCustomAnimationStates(MegaSprite controller)`, static helper `SetupAnimationState(controller, idleName, deadName, deadLoop, hitName, hitLoop, attackName, attackLoop, castName, castLoop, relaxedName, relaxedLoop)` → `animator.AddAnyState("Idle"/"Dead"/"Hit"/"Attack"/"Cast"/"Relaxed", ...)`; omitted names fall back to idle. `RegisterSceneConversions()` registers `NCreatureVisuals/NRestSiteCharacter/NMerchantCharacter/NEnergyCounter`. `PlaceholderCharacterModel` defaults every path to Ironclad's.
- **Wiki Creature Visuals** (https://alchyr.github.io/BaseLib-Wiki/docs/scenes/creature-visuals.html) [READ]: root **Control**; children `%Visuals` (Node2D), `%PhobiaModeVisuals` (opt), `%Bounds` (Control), `%IntentPosition` (Marker2D), `%CenterPos`, `%OrbPos` (opt), `%TalkPos` (opt). NodeFactory-converted scenes only require `Visuals`. Static PNG: `NodeFactory<NCreatureVisuals>.CreateFromResource("res://...png")`. Godot animation: `AnimationPlayer`, `AnimationPlayer2D`, or `AnimationTree` (Tree Root must be `AnimationNodeStateMachine`, transitions "At End"); recognised names are the `CreatureAnimator` consts or "idle","attack","cast","hurt","die" (case-insensitive). **The "Spine" section is an empty stub.** Merchant page: `NMerchantCharacter`, plays `relaxed_loop` (alt `idle`) and `die`; "first child node must be the Spine node". No rest-site wiki page.
- Spine version 4.2.43 [READ]; BaseLib imports `MegaCrit.Sts2.Core.Bindings.MegaSpine` — the game wraps spine-godot in its own MegaSprite binding (confirmed locally in decompile_v0107).

## 3. Templates / tooling

- **ModTemplate-StS2** [READ]: commits through 2026-08-22 ("use assembly in PatchAll", "adjust publicize implementation", "add example godot paths to build props", potion-image fallback in character template, v2.5.1 on Aug 12). Setup: latest **MegaDot** (MegaCrit's Godot fork, https://megadot.megacrit.com) or matching Godot .NET; .NET 9 SDK; `dotnet new install Alchyr.Sts2.Templates`; set `GodotPath` in `Directory.Build.props`; "Publish" generates `.pck`. Game PCK format is Godot **4.5.1**. Wiki updated 2026-07-11 and links the Blender guide below.
- **Sts2-ModSmith** (cpimhoff): "only use for documentation, defer to BaseLib".
- Blocked: GitHub API (403) and github.com tree pages; raw.githubusercontent.com used instead.

## 5. Community write-ups / official docs

- **Blender cut-out pipeline** (https://github.com/r2Nexus/The-Engineer/wiki, Jun 2026) [READ]: Krita layers → PNG parts (~800×1000 canvas, ≤~25 parts) → Blender "Images as Planes", bone rig, IK, actions named `idle/attack/cast/hurt/die` (3–5 frame snappy actions), export **glTF .glb** → Godot: inherited scene + view scene with `AnimationPlayer`, `AnimationTree` state machine, orthogonal `Camera3D`, inside `Visuals/CharBox/SubViewportContainer/SubViewport` (Own World 3D + Transparent BG), plus `Bounds/IntentPos/CenterPos/OrbPos/TalkPos`. Includes a Blender add-on "StS2 Tool Kit". Main **no-Spine-licence** workaround; BaseLib picks it up via AnimationPlayer/AnimationTree support.
- **Custom Skeleton Loader** (Nexus 505, Khiral, 2026-04-13): exports game skeletons (.spskel→.skel, .spatlas→.atlas) and hot-swaps via `ReplaceResources/{skeleton}/`; for reskinning, not new characters.
- **STS2 Character Mod Creator** (https://slay.spencerstiles.com, Nexus 299, Mar 2026): no-code web tool supporting Main v0.107.1 / Beta v0.111.0; modes Static / Basic (image per pose) / Full (spritesheet per pose, 256–1024px per frame), 512×512 body sprite, stackable energy-orb PNG layers.
- **Official**: MegaCrit's June 2026 Neowsletter confirms Workshop enabled and points to `github.com/megacrit/sts2-mod-uploader` (v0.1.0, 2026-06-18) and Alchyr's wiki as the docs; wiki.gg: "STS2 does not have a formal modding API". No SDK. Nothing found on Spine 3.x/DragonBones→4.2 conversion besides the tutorial's "SpineSkeletonDataConverter" mention.

## 6. Workshop publishing

[READ, tutorial 11 + uploader README]: run `ModUploader.exe` to create `NewModWorkspace`, put raw `.json/.dll/.pck` in `Content/`, edit `workspace.json`, add `image.jpg` (**≤1 MB**), `ModUploader.exe upload -w <folder>`; updates reuse `mod_id.txt`. **Tags cannot be changed after upload** — set "Characters" (plus Cards/Relics/QoL, language tags like "English"/"schinese"). Dependencies are workshop IDs (BaseLib = 3737335127). Workshop browse has a "Characters" tag filter.
